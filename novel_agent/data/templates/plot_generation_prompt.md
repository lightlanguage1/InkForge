【节拍质量标准（生成前内化）】
════════════════════════════════════════

每个节拍必须通过以下全部检查：

粒度检查
  · description 是一个简短的中文句子（10-20 字），最多含一个逗号或连接词
  · 每个节拍只描述一个主要推进：一个决定、一个行动、或一个明确后果
  · 如果一个节拍包含多个事件 → 拆成多个独立节拍，不要压缩
  · 不要将跨越长时间的序列压缩为单个节拍

具体性检查
  · 优先选择具体的外部行动和可观察变化，而非模糊总结或内心独白
  · 单个 description 中专有名词不超过 3 个
  · plot_threads 每个节拍最多列 3 个，只选最相关的

推进性检查
  · 每个节拍必须与已有开放线索或角色弧线产生可追踪的关联
  · 不重复最近场景中已发生的事件或情感节拍
  · tension_target 根据叙事节奏设置（1-10），避免连续多个节拍张力相同
